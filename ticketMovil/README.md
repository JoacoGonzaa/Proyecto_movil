## 📱 Funcionalidades

- Listado de eventos desde API.
- Detalle de evento con selección de entradas dinámica.
- Carrito de compras y Checkout.
- Historial de compras con persistencia local (AsyncStorage).
- Integración con Mapas y Share nativo.

## 🛠️ Instalación

1. Clonar el repositorio.
2. Instalar dependencias:
   ```bash
   yarn install
   ```
